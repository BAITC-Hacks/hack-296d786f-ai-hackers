# Классификатор обращений

Небольшой скрипт на Python, который читает пять обращений
из файла messages.txt. Для каждого обращения программа
выводит категорию и один черновик ответа на русском языке.

## Как запустить

1. Установить Python 3.
2. Скачать main.py и messages.txt в одну папку.
3. Открыть терминал в этой папке.
4. Выполнить команду: python3 main.py

Дополнительные библиотеки и ключи API не нужны.

## Как работает

Категория определяется правилами по ключевым словам.
Ответ выбирается из готовых шаблонов.

В этом решении категории понимаются так:
- справка — запрос информации;
- жалоба — сообщение о проблеме;
- другое — остальные обращения, включая запись на консультацию.

## Результат для обращений из задания

1. Получение справки о месте учёбы — справка.
2. Очередь и холодная еда в столовой — жалоба.
3. Запись на консультацию — другое.
4. Пропавший Wi-Fi — жалоба.
5. Расположение гостевой парковки — справка.

Для каждого обращения выводится черновик ответа.
Программа не отправляет ответы и не оформляет заявки.

## Ограничения

Правила рассчитаны на примеры из задания.
Для других формулировок потребуется расширить список правил.
