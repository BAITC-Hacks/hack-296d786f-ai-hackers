# 🔕 Тихий пульт — фильтр алертов

Меньше шума — больше внимания важному.

Небольшой скрипт, который читает восемь событий из events.json,
показывает только события уровня critical и выводит их количество.

## Файлы

- events.json — исходные события с уровнями info, warn и critical.
- main.py — чтение данных, фильтрация и вывод результата.
- README.md — описание и инструкция запуска.

## Как запустить

Требуется Python 3. Дополнительные библиотеки, API и агенты не нужны.

Откройте терминал в папке проекта и выполните:

```bash
python3 main.py
```

## Как работает

Скрипт читает JSON и проверяет поле level каждой записи.
В результат попадают только записи, у которых level равен critical.
Последняя строка показывает количество критичных событий.

## Результат для данных из задания

```text
disk 90% (critical)
payment failed (critical)
db timeout (critical)
критичных 3
```

Из восьми событий остаются три критичных.
Четыре события info и одно событие warn не выводятся.

Скрипт использует уровни важности из файла:
он не определяет критичность по тексту события.
