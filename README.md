# Два небольших помощника: обращения и алерты

Решения двух репетиционных заданий трека «Агентные системы».
Написаны на Python 3. Дополнительные библиотеки и ключи API не нужны.

## Как запустить

Скачайте репозиторий через Code → Download ZIP и распакуйте архив.
Откройте распакованную папку в VS Code, затем Terminal → New Terminal.

Запускайте команды из папки, в которой находятся файлы программ.

## 1. Классификатор обращений

Файлы: classifier.py и messages.txt.

Запуск:

```bash
python3 classifier.py
```

Скрипт читает пять обращений и для каждого печатает категорию
и один черновик ответа на русском языке.

Категории определяются правилами по ключевым словам:
- справка — запрос информации;
- жалоба — сообщение о проблеме;
- другое — остальные обращения.

Ожидаемые категории для заданных примеров:
справка, жалоба, другое, жалоба, справка.

Ответы берутся из шаблонов и никуда не отправляются.
Правила рассчитаны на примеры задания; для новых формулировок
их потребуется расширить.

## 2. «Тихий пульт» — фильтр алертов

Меньше шума — больше внимания важному.

Файлы: alert_filter.py и events.json.

Запуск:

```bash
python3 alert_filter.py
```

Скрипт читает восемь событий и выводит только записи,
у которых поле level равно critical, затем печатает их количество.

Ожидаемый вывод:

```text
disk 90% (critical)
payment failed (critical)
db timeout (critical)
критичных 3
```

Из восьми событий остаются три критичных.
Четыре события info и одно событие warn не выводятся.
Критичность берётся из данных, а не определяется по тексту.
